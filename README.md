# Assignment 2: Basics of Application Profiling using Score-P and CUBE.
The LaTeX document is generated using github actions that are executed every time a new commit is merged into this repo. Each document has a persistence of 7 days from the moment the commit is merged.

To view the latest document go to https://github.com/wivill/sp2136-cilk_omp_merge_sort/actions, click on the latest Compile LaTeX action, go to the Artifacts view and download the one named "Assignment02".

If more than 7 days have passed since the last commit, you can click on "Re-run all jobs" to generate the Artifacts (and hence the LaTex report) again.
